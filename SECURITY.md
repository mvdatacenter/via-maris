# Security policy

`via-maris` decides which package versions reach the machines behind it, so a flaw that lets a refused version through, or lets a request bypass the check, is a security vulnerability.

## Reporting a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. The report reaches the maintainers only.

Please include the affected version or commit, the steps that reproduce the problem, and what an attacker gains from it. Keep it out of public issues, pull requests and discussions until a fix is released.

We acknowledge a report within three working days and tell you the planned fix or our assessment within fourteen days. The fix is released with a GitHub security advisory, and the reporter is credited there unless they ask not to be.

## Supported versions

There is no release yet. Once releases exist, security fixes go to the latest release.
