# Contributing

Thank you for your interest in `via-maris`.

## Issues

Bug reports and feature requests are welcome as GitHub issues. A security problem goes through the private route in [SECURITY.md](SECURITY.md) instead.

## Pull requests

MV Data accepts outside pull requests once it publishes a contributor license agreement for this project. The agreement lets MV Data offer the code under other terms as well as the GNU Affero General Public License, version 3. Until it is published, outside pull requests are closed without merging. An issue describing the change is the way to propose it in the meantime.
